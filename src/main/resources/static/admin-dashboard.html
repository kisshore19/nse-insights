Downloads constituent symbols for all supported NSE indices and upserts into index_master. Most indices use CSV files from NSE Archives. Indices marked NSE API (NIFTYFINSERVICE, NIFTYCHEMICALS) are fetched via the NSE live equity-indices API since their constituent CSVs are not published on archives.
